# ctyun_ec_cloud_gateway (Resource)
-> 管理云企业路由器



## Example

```terraform
terraform {

    ctyun = {
      source = "ctyun-it/ctyun"

  env = "prod"
}

  ec_id       = ctyun_express_connect.example.id

}
```
