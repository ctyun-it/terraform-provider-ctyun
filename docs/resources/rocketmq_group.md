## Schema

### Required

- `broker_names` (Set of String) 关联的 Broker 节点名称列表，需填写实际部署的 Broker 节点名称，不可为空数组
- `instance_id` (String) RocketMQ 实例 ID
- `name` (String) 订阅组名称，需符合 MQ 订阅组命名规范（字母、数字、下划线组合，长度 1-64 字符），不可重复

### Optional

- `consume_broadcast_enable` (Boolean) 是否开启广播消费，true 表示开启广播消费，false 表示关闭广播消费，默认 true
- `consume_enable` (Boolean) 是否允许消费，true 表示允许消费，false 表示禁止消费，默认 true 支持更新
- `first_consume_mechanism` (Number) 首次消费机制，0:从最小位点开始消费，1:从最新位点开始消费，默认 0
- `pull_mechanism` (Number) 拉取机制，0:服务器主动推送，1:客户端拉取，默认 1
- `region_id` (String) 资源池 ID，如果不填则默认使用 provider ctyun 中的 region_id 或环境变量中的 CTYUN_REGION_ID
- `remark` (String) 备注信息
- `retry_max_times` (Number) 最大重试次数，消费失败后最多重试次数，默认 16

### Read-Only

- `id` (String) 订阅组 ID
