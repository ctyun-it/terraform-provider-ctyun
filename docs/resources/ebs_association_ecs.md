# ctyun_ebs_association_ecs (Resource)
-> 管理云硬盘和云主机的绑定关系（已废弃，请使用ctyun_ecs_data_volume进行绑定）



## Example

```terraform
terraform {
  required_providers {
    ctyun = {
      source = "ctyun-it/ctyun"
    }
  }
}

# 可参考index.md，在环境变量中配置ak、sk、资源池ID、可用区名称
provider "ctyun" {
  env = "prod"
}
resource "ctyun_ebs_association_ecs" "ebs_association_ecs_test" {
  ebs_id      = "86517323-d3f5-48cb-b278-a124e98fbc3d"
  instance_id = "0b9897c8-ff01-42b4-c4c2-6a427d8b2e9a"
}
```

## Schema

### Required

- `ebs_id` (String) 磁盘id
- `instance_id` (String) 云主机id，多可用区资源池下，云硬盘和云主机必须在同个az才能支持挂载；XSSD类型云硬盘支持绑定的云主机规格包括：s8,m8,c8,c8ne,m8ne,s8e,c8e,m8e,hc3,hm3

### Optional

- `region_id` (String) 资源池ID，如果不填则默认使用provider ctyun中的region_id或环境变量中的CTYUN_REGION_ID

### Read-Only

- `id` (String) ID
