## Schema

### Required

- `broker_names` (Set of String) 关联的 Broker 节点名称列表，需填写实际部署的 Broker 节点名称，不可为空数组
- `instance_id` (String) RocketMQ 实例 ID
- `name` (String) 主题名称，需符合 MQ 主题命名规范（字母、数字、下划线组合，长度 1-64 字符），不可重复
- `queue_nums` (Number) 主题的读写队列数量，用于控制消息读写入的并发能力，需为正整数

### Optional

- `order` (Boolean) 标识主题是否为顺序消息队列，true 表示顺序队列，false 表示普通队列，默认 false
- `perm` (Number) 主题的权限控制值，固定可选值为 2（只读）、4（只写）、6（读写），默认推荐 6 支持更新
- `region_id` (String) 资源池 ID，如果不填则默认使用 provider ctyun 中的 region_id 或环境变量中的 CTYUN_REGION_ID
- `remark` (String) 备注信息 支持更新

### Read-Only

- `id` (String) 主题 ID
