# ctyun_dhcpoptionset_association_vpc (Resource)
-> 管理DHCP选项集和VPC的绑定关系



## Example

```terraform
terraform {
  required_providers {
    ctyun = {
      source = "ctyun-it/ctyun"
    }
  }
}

provider "ctyun" {
  env = "prod"
}
resource "ctyun_dhcpoptionset" "example" {
  name        = "dhcpoptionset"
  description = "Example DHCP option set"
  domain_name = "example.com"
  dns_list    = ["8.8.8.8", "114.114.114.114"]
}
resource "ctyun_dhcpoptionset_association_vpc" "example" {
  dhcp_option_sets_id = ctyun_dhcpoptionset.example.id
  vpc_ids             = ["vpc-id-example1", "vpc-id-example2"]
}
```

## Schema

### Required

- `dhcp_option_sets_id` (String) DHCP选项集ID
- `vpc_ids` (Set of String) VPC ID列表 支持更新，至少输入一个，最大支持10个

### Optional

- `region_id` (String) 资源池ID，如果不填则默认使用provider ctyun中的region_id或环境变量中的CTYUN_REGION_ID

### Read-Only

- `id` (String) 资源唯一标识，格式为dhcp_option_sets_id,region_id
