# ctyun_ec_sdwan_instance (Resource)
-> 管理云间高速SDWAN网络实例



## Example

```terraform
terraform {
  required_providers {
    ctyun = {
      source = "ctyun-it/ctyun"
    }
  }
}

provider "ctyun" {
  project_id = "0"
}

resource "ctyun_express_connect" "example" {
  name        = "express_connect_dependence"
  description = "云间高速example专用"
}

  ec_id       = ctyun_express_connect.example.id
  name        = "cloud_gateway_xinan1"
  description = "云间高速开发测试专用"
  region_id   = "200000002368"
  region_name = "西南1"
}

resource "ctyun_sdwan" "demo" {
  name        = "sdwan_demo"
  description = "样列"
}

resource "ctyun_ec_sdwan_instance" "example" {
  ec_id       = ctyun_express_connect.example.id
  cgw_id      = ctyun_ec_cloud_gateway.example.id
  sdwan_id    = ctyun_sdwan.demo.id
  rtb_id      = ctyun_ec_cloud_gateway.example.rtb_id
  weights     = 100
  route_learn = 1
  route_sync  = 1
}
```

## Schema

### Required

- `cgw_id` (String) 云网关ID
- `ec_id` (String) 云间高速ID
- `rtb_id` (String) 云网关默认路由表ID
- `sdwan_id` (String) sdwan ID

### Optional

- `route_learn` (Number) 路由学习开关，开启后云网关自动学习网络实例路由，取值范围: 1:学习 0:不学习，默认学习
- `route_sync` (Number) 路由同步开关，开启后云网关路由自动同步到网络实例，取值范围: 1:同步 0:不同步，默认同步
- `weights` (Number) 权重，sdwan默认60，无冗余实例则不传 支持更新

### Read-Only

- `id` (String) 网络实例ID
