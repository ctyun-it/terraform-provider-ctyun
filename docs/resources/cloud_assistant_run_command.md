# ctyun_cloud_assistant_run_command (Resource)
-> 在云主机中执行一段Shell、PowerShell、Bat或Python类型的脚本命令



## Example

```terraform
terraform {
  required_providers {
    ctyun = {
      source = "ctyun-it/ctyun"
    }
  }
}

# 可参考index.md，在环境变量中配置ak、sk、资源池ID、可用区名称
provider "ctyun" {
  env = "prod"
}


data "ctyun_ecs_instances" "test" {
  page_size = 1
}

output "ctyun_ecs_instances_test" {
  value = data.ctyun_ecs_instances.test
}
# 执行云助手命令（Shell类型）
resource "ctyun_cloud_assistant_run_command" test {
  instance_ids    = data.ctyun_ecs_instances.test.instances[0].id
  command_name    = "hello_terraform"
  command_type    = "shell"
  command_content = "echo hello terraform"
  description     = "运行命令样例"
  save_command    = false
  timeout         = 30
}
```

### Required

- `instance_ids` (String) 待执行命令的弹性云主机ID列表，使用英文逗号分割，一次最多不超过100台

### Optional

- `command_content` (String) 加密后的命令内容，长度不可超过24KB
- `command_name` (String) 命令名称，长度不超过128个字符
- `command_type` (String) 命令类型：shell、bat、powershell、python
- `description` (String) 命令描述，长度不超过512个字符
- `enabled_parameter` (Boolean) 是否启用自定义参数，默认false
- `parameter` (Map of String) 自定义参数，key和value均只支持string
- `region_id` (String) 资源池 ID
- `save_command` (Boolean) 是否保存命令，默认false
- `timeout` (Number) 命令超时时间，默认60秒
- `working_directory` (String) 命令在实例中运行目录，Linux默认/tmp，Windows默认C:\Windows\System32
